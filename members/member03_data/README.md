# 成员 3 · 公开数据审查、数据管理与标注质检

## 职责

公开数据可用性审查、场景任务卡、数据划分、标注规范、交叉审核和测试集封存。

**交付物：** 公开数据审查表；scene_id 总账；标注规范与转换器；划分清单；GT 文件；类别/场景/对象支持数。

**协作：** 全员按任务卡供图、标注和复核；成员 2 提供拍摄条件；向成员 4/5/6 提供开发数据，独立测试受控交接。

**验收：** 无重复场景跨分区；每个可判断对象有可信类别与框；数量能由标注重算；未知规格不被硬映射。

**边界：** 组织数据工作，不包办清洗和标注；开发数据与封存测试分开；不向调参人员泄露测试标签或结果。

## 提交方式

任务分支 `member03/简短任务名`，仅修改 `members/member03_data/`。公共接口/跨目录变更交组长整合。时间线见 [progress.md](progress.md)。
