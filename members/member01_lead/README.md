# 组长 / 成员 1 · 需求、系统集成与项目管理

## 职责

课程要求、统一接口、版本冻结、进度协调、决策记录、报告统稿和最终验收。

**交付物：** 课程检查表；接口规范；冻结清单；decision_stage2.md / decision_final.md；整合报告与演示安排。

**协作：** 接收成员 3 的数据清单、4/5/6 的模型和评测、7 的统一入口；独立核查评价规则。

**验收：** 四个模型 ID 可用；必需功能与提交物齐全；至少两个人能独立启动完整系统。

**边界：** 不代写全部模块和个人报告；不替代成员 3 的真值质检或成员 7 的界面实现。

## 提交方式

任务分支 `member01/简短任务名`，仅修改 `members/member01_lead/`。公共接口/跨目录变更交组长整合。时间线见 [progress.md](progress.md)。

- 验证命令与真实结果：待填写。
- 已知限制/失败状态：待填写。
