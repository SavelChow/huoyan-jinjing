# 最终执行计划 v3.0

## 路线

公开数据抽查 → 少量自采与 Pilot → 三个标准基线 → 冻结后独立测试 → 依据真实错误选择一条改进 → 新独立测试与现场展示。
五类/拒绝标签和接口见 shared。主线是规格合规与计数，不扩展损伤检测、机械分拣或移动端。

## 数据

Fastener Object Detection 优先审查，MVTec Screws 备用；公开规格未经核实不硬映射。
训练 100（含 Pilot 35），验证 30，Stage 2 测试 40（计划 20 PASS/20 FAIL），Stage 3 测试 60，共 230 个独立场景为起步目标。需要时训练定向扩至约 160；数量并非效果保证或课程强制总量。
覆盖缺少、多出、空场景、仅目录外、数量正确但混入目录外、近规格混放；按场景分区、先分区后增强，区分已见/未见目录外型号。

首选提升为局部外观+尺度几何复核；若主因是漏框或光照，则改为候选发现或光照稳健处理，实验随之同步修改。Stage 2 已须具备基本尺寸拒绝，不能把首次实现必需能力当创新。
主指标关注数量正确但混入相似错规格时的错误 PASS；同时报告全部目录外结果、合法件误拒、弃判/覆盖率、FAIL P/R/F1、各类对象 P/R（IoU≥0.50）、计数 MAE、五类向量全对率和 Median/P95 延迟。
