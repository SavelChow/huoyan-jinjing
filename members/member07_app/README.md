# 成员 7 · 摄像头、界面、统一入口与复现

## 职责

新帧采集、模型切换、预期数量控件、结果展示、批量入口、导出、端到端计时与启动说明。

**交付物：** 界面；predict.py；四种模型路由；CSV/JSON 输出；时延记录；依赖与启动文档；第二套启动能力。

**协作：** 各模型负责人提供统一接口与配置；组长验收；成员 4/5 负责指标算法；成员 3 提供输入清单规范。

**验收：** 真实新帧可用；数量修改不污染模型输出；不支持/需复核状态明确；命令行与界面输出一致。

**边界：** 不包揽所有指标计算或模型训练；延迟包含预处理、推理、后处理和显示更新调用，GPU 工作需同步。
